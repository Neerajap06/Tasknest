# TaskNest – Smart To-Do & Productivity Dashboard 🧠✨

TaskNest is a clean, responsive, and lightweight frontend dashboard built with HTML, CSS, and JavaScript. It helps users manage daily tasks, monitor productivity, and stay focused.



## 🚀 Features

- ✅ Add, edit, and delete tasks
- 🎯 Mark tasks as complete/incomplete
- 🗂️ View tasks by status
- 🌗 Light/Dark mode toggle
- 📅 Task deadlines with countdown
- 📊 Productivity insights (basic stats)


## 🔧 Tech Stack

- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript (ES6+)

## 🧠 How It Works

1. Tasks are stored in browser memory (localStorage)
2. User can add, complete, delete, and edit tasks
3. UI updates dynamically based on interactions
